## Verdict (short)

Strong brand object, incomplete label world. Release pages and the listening room are already premium; homepage narrative and artist surfaces are where quality leaks.

## Top 3 UI upgrades

1. Artwork-forward featured release in the home hero  
2. Scale artist photography + real bios  
3. Unify light-page “station” chrome with the dark brand  

## Top 3 homepage additions

1. Featured release (hero / now-on strip)  
2. Featured artist spotlight  
3. Philosophy micro-section (“Music we want to keep”)
