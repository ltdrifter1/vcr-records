# VCR Recordings

Independent electronic music label site — premium, design-forward frontend for [vcrrecords.com](https://www.vcrrecords.com).

## Stack

Static HTML/CSS/JS. Shared design system in `vcr.css` + interactions in `vcr.js`.

## Key pages

- `index.html` — homepage
- `artists.html` / `artist-*.html` — roster + editorial artist profiles
- `shop.html` / `product-*.html` — merch store + product detail
- Release pages (`champ.html`, `summer.html`, etc.) — existing catalog

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
